# .dot blog
Новинний сайт на чистих HTML, CSS і JS. Відкрийте `index.html` у браузері або через Live Server у VS Code.

- Нові статті додаються в масив `ARTICLES` у `js/main.js`, а сторінка статті — копія `article.html`.
- Для GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.
